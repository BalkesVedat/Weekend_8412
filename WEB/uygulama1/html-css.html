HTML & CSS

Web sayfasının yapısını ve görünümünü oluşturmayı öğren.

1. HTML nedir?

HTML, web sayfasının içeriğini ve yapısını oluşturur. 

<h1>Merhaba Dünya</h1>

<p>
    İlk web sayfamı oluşturuyorum.
</p>

<a href="https://example.com">
    Siteye git
</a>

2. Semantik HTML

Sayfanın bölümlerini anlamlı HTML elementleriyle tanımlayabiliriz. 

<header>
    Site başlığı
</header>

<nav>
    Menü
</nav>

<main>

    <section>
        Ana içerik
    </section>

</main>

<footer>
    Alt bilgi
</footer>

3. CSS nedir?

CSS, HTML elementlerinin görünümünü kontrol eder. 

body {
    background: #f5f5f5;
}

h1 {
    color: blue;
}

.card {
    padding: 20px;
    border-radius: 10px;
}

4. Flexbox

Flexbox elementleri yatay veya dikey olarak düzenlemek için kullanılır. 

.menu {
    display: flex;

    justify-content: center;

    gap: 20px;
}

5. Responsive Tasarım

Web sitesinin telefon, tablet ve bilgisayarlarda düzgün görünmesini sağlarız. 

@media (max-width: 700px) {

    .cards {
        grid-template-columns: 1fr;
    }

}
