JavaScript

Web sayfalarına hareket ve etkileşim kazandır.

1. Değişkenler

Bilgileri saklamak için değişkenler kullanılır. 

const isim = "Ali";

let yas = 20;

yas = 21;

console.log(isim);
console.log(yas);

2. Fonksiyonlar

Tekrar kullanılacak kodları fonksiyon haline getirebiliriz. 

function topla(a, b) {

    return a + b;

}

const sonuc = topla(10, 20);

console.log(sonuc);

3. Diziler

Birden fazla değeri tek bir değişkende saklayabiliriz. 

const isimler = [
    "Ali",
    "Ayşe",
    "Mehmet"
];

console.log(isimler[0]);

isimler.forEach(isim => {
    console.log(isim);
});

4. DOM

JavaScript ile HTML elementlerini seçebilir ve değiştirebiliriz. 

const baslik =
    document.querySelector("#baslik");

baslik.textContent =
    "Yeni Başlık";

5. Event

Kullanıcının yaptığı işlemleri event listener ile yakalayabiliriz. 

button.addEventListener(
    "click",
    () => {

        console.log("Tıklandı!");

    }
