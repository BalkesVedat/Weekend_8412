Javascript ile Form Nesnelerinden veri çekme, veri aktarma, hesaplama yapma, if-else

Sayfa Üzerinde bulunan Form nesnelerinden (input) veri çekmek için, nenelerin "id" attribute lerinden yararlanabiliriz. document.getElementById metodunu kullanarak nesnelere id leri üzerinden erişebiliriz. Bazı nesneler (Örneğin: başlıklar, paragraflar..v.b.) içerisine HTML içeriği konulabildiğinden bu nesnelerin "innerHTML" özeliklerini kullanabiliriz. İçerisine sadece text girilen nesnelerden "innerText" özelliğini kullanabiliriz. Form nesnelerinden ise, "value" özelliklerinden veri çekebilir ya da veri aktarabiliriz.

Değişkenler

Javascript te de bellekte geçici süreliğine veri kaydedilebilir. Temel olarak 3 tip değişken bildirimi yapılabilir. Tipe göre (int, string, bool, double, v.b.) ayrı değişken bildirimi yoktur. Burada değişkenler kullanım alanına göre belirlenir ve bir değişken içerisine her türden veri atanabilir.

Değişken Tanımlama İfadeleri:

  • var : Global değişken tanımlar. Yani js kodu içerisinde bu değişkene her yerden erişilebilir. Aynı scope içinde birden fazla aynı isinde değişken tanımlaması yapılabilir. Önceki değişken silinerek yenisi oluşturulur.
  • let : Lokal değişken tanımlar. Yani let ile tanımlanan değişken sadece tanımlandığı scope ta geçerlidir. Aynı scope içinde aynı isimde tek değişken oluşturulabilir.
  • const: Sabit değer tutan alanlar tanımlar. Yani const ile tanımlanan sabite atanan veri daha sonra değiştirilemez. Bu nedenle verisi sabit alan ilk tanımlanırken atanır. Aynı Let gibi sadece tanımlandığı scope ta geçerlidir. Aynı scope ta aynı isimde tek teğişken oluşturulabilir.

Karar Yapıları

if (koşul) { koşul doğru ise yapılacak işlemler } else { yanlış ise yapılaca işlemler }

Bir koşulun değerine göre 2 işlemden birinin çalışmasını sağlar.

Kontrol edilecek durum 2 den fazla ise; 'if' / 'else if' / 'else' yapısı kullanılarak her durum için if kontrolü yapılır.

Alternatif olarak çoklu durum kontrolü için switch-case yapısı da kullanılabilir.
